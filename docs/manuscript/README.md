# Manuscript Workspace (`M9`)

This directory is the source tree for conference paper, supplementary material, and internal review records.

## Files
- `outline.md` — section ownership and writing responsibilities (`T9.1`).
- `conference_paper.md` — consolidated manuscript draft (`T9.2`, `T9.3`).
- `appendix_reproducibility.md` — supplementary reproducibility appendix (`T9.5`).
- `internal_review_log.md` — two-pass internal review closure (`T9.4`).
- `figures/` — script-generated publication figures from `scripts/publication/build_figures.py`.
- `arxiv/` — arXiv-style LaTeX source package (`main.tex`, `references.bib`) for preprint upload.

## Evidence Policy
Headline claims in this manuscript are restricted to real-backed DFT and benchmark outputs.
Simulation-only artefacts appear as ablations in the appendix.
